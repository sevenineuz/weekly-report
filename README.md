# Еженедельный отчёт для родителей — Sevenine

Инструмент для преподавателей Sevenine English School (Ташкент): заполнить отчёт
за неделю и сохранить его картинкой (PNG 540×960) для отправки родителям.

**Открыть:** https://sevenineuz.github.io/weekly-report/

## Что внутри
- Ученик, группа (Kids 1–4 / A1–C1), преподаватель, неделя
- Оценка недели 1–3 и «Ученик недели» с обоснованием
- Звёзды по навыкам + комментарии
- «Наблюдение учителя» и «Совет для дома» с подсказками-чипами,
  которые подбираются по уровню группы и по выставленным звёздам
- Три языка интерфейса: RU / UZ / EN
- Экспорт в PNG (html2canvas)

Один файл, `index.html`, без сборки.
